# MH Chat

A simple native Android chat app that talks to a self-hosted [OmniRoute](https://github.com/diegosouzapw/OmniRoute)
AI gateway (OpenAI-compatible API).

## Setup on your phone

1. Install the APK.
2. Open the app, tap the ⋮ menu → **Settings**.
3. Fill in:
   - **Endpoint URL** (e.g. `https://omniroute-es3t.onrender.com`)
   - **API key** (your OmniRoute key — stored only on your device, never logged)
   - **Model** — tap **Load models** to fetch the list from the gateway, or type one manually.
4. Tap **Save** and start chatting.

No account, no tracking, no extra permissions — only INTERNET.
